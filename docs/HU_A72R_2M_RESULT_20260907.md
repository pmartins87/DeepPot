# DeepPot HU A72r exact-state deep stability result

Date: 2026-09-07

## Purpose

This closes the raw cross-seed iteration ladder for the fixed HU flop `Ah 7d 2c` under the provisional 2% pot-rake model. It is not an invitation to keep increasing iterations indefinitely.

Representation is lossless with respect to strategic card state: exact flop+hole states are collapsed only by global suit isomorphism. No equity, potential, draw, rank-class, or 169-hand abstraction is used.

## Interpretation

The exact representation is converging materially as visits increase. The previous 10k result was dominated by sampling sparsity, not by an intrinsically unmanageable state space.

Raw probability disagreement is not by itself a sufficient release metric. Near-indifferent information sets can retain materially different mixed probabilities while having little or no actionable EV difference. Therefore the project will not keep extending this same ladder to 5M, 10M, 20M, etc. merely to force P(STAY) agreement.

The next finite validation step is unilateral-response gain against the cross-seed consensus policy, measured on an independent holdout sample with confidence intervals.

## Decision

**A72r iteration ladder CLOSED at 2M x 3 seeds.**

No further A72r cross-seed iteration escalation is planned unless a later identified solver bug invalidates these runs. The next gate is response/EV quality, not another raw-stability rung.
